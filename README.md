REST API Development Project

This project is developed as part of a Python Programming Internship.

The application is built using Flask and SQLite and demonstrates the basic CRUD (Create, Read, Update, Delete) operations for student records.

Project Features

1. Add new student records.
2. View available student records.
3. Update existing student details.
4. Delete student records when required.
5. Store and manage data using SQLite database.

Technologies Used

- Python
- Flask
- SQLite

Project Structure

- app.py – Main application file
- requirements.txt – Project dependencies
- README.md – Project documentation
- students.db – SQLite database (generated automatically)

How to Run

1. Install the required package:
   pip install flask

2. Run the application:
   python app.py

3. Open the application in a browser using:
   http://127.0.0.1:5000

Purpose of the Project

The purpose of this project is to understand REST API development, database integration, and CRUD operations using Python and Flask.
