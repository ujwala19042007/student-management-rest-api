Student Management REST API Documentation

1. Project Overview

This project is a RESTful API developed using Python Flask and SQLite. It allows users to create, view, update, and delete student records.

2. Base URL

http://127.0.0.1:5000

3. API Endpoints

GET /
Description: Checks whether the API is running.

GET /students
Description: Retrieves all student records.

GET /students/<student_id>
Description: Retrieves a student by ID.

POST /students
Description: Adds a new student.

Example JSON request:
{
"name": "Ravi",
"age": 20,
"course": "Python"
}

PUT /students/<student_id>
Description: Updates an existing student's details.

Example JSON request:
{
"name": "Ravi Kumar",
"age": 21,
"course": "Flask"
}

DELETE /students/<student_id>
Description: Deletes a student by ID.

4. Technologies Used

* Python
* Flask
* SQLite
* JSON

5. Error Handling

The API validates input data and returns appropriate error messages for invalid requests or student IDs that do not exist.

6. How to Run

7. Install dependencies using: pip install -r requirements.txt

8. Run the application using: python app.py

9. Open http://127.0.0.1:5000/students in a browser to view student records.

Note: The base URL is local and works on the computer running the application.
